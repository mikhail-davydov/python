# FastAPI Интернет-магазин

REST API для интернет-магазина, построенный на **FastAPI** с асинхронным ORM **SQLAlchemy** и **JWT**-аутентификацией.

## Возможности

- **Аутентификация и авторизация**
  - Регистрация пользователей с ролями: `buyer`, `seller`, `admin`
  - Логин через OAuth2 (логин/пароль)
  - JWT access- и refresh-токены
  - Обновление access- и refresh-токенов

- **Управление категориями** (только для `admin`)
  - Создание, обновление, мягкое удаление
  - Иерархические категории (родительские / дочерние)

- **Управление товарами** (только для `seller`)
  - Создание, обновление, мягкое удаление своих товаров
  - Просмотр всех активных товаров
  - Фильтрация по категориям
  - Поле рейтинга (пересчитывается автоматически)

- **Отзывы и рейтинги** (только для `buyer`)
  - Создание отзыва (оценка 1–5 + комментарий)
  - Мягкое удаление своего отзыва или отзыва через админ-панель
  - Автоматический пересчёт среднего рейтинга товара

## Стек технологий

| Компонент | Технология |
|---|---|
| Фреймворк | FastAPI 0.162 |
| ORM | SQLAlchemy 2.1 (async) |
| БД | SQLite (ecommerce.db) |
| Миграции | Alembic |
| Аутентификация | PyJWT (HS256) |
| Хеширование паролей | argon2-cffi |
| Сервер | Uvicorn |

## Структура проекта

```
app/
├── main.py          # Точка входа, регистрация роутеров
├── config.py        # Конфигурация (SECRET_KEY, ALGORITHM)
├── database.py      # Подключение к БД, Base
├── db_depends.py    # Зависимость get_async_db
├── auth.py          # Утилиты JWT и хеширования
├── schemas.py       # Pydantic-схемы
├── models/          # SQLAlchemy-модели
│   ├── users.py
│   ├── categories.py
│   ├── products.py
│   └── reviews.py
└── routers/         # API-эндпоинты
    ├── users.py     # Регистрация, логин, токены
    ├── categories.py # CRUD категорий
    ├── products.py  # CRUD товаров
    └── reviews.py   # CRUD отзывов
```

## Установка и запуск

### 1. Зависимости

```bash
pip install -r requirements.txt
```

### 2. Переменные окружения

Создайте файл `.env` в корне проекта:

```env
SECRET_KEY=your-secret-key-here
```

### 3. Миграции (опционально)

```bash
alembic upgrade head
```

### 4. Запуск сервера

```bash
uvicorn app.main:app --reload
```

Сервер запустится на `http://localhost:8000`.

## Эндпоинты

### Аутентификация

| Метод | Путь | Описание | Роли |
|---|---|---|---|
| `POST` | `/users/` | Регистрация пользователя | все |
| `POST` | `/users/token` | Логин, получение токенов | все |
| `POST` | `/users/refresh-token` | Обновление refresh-токена | все |
| `POST` | `/users/refresh-access-token` | Получение нового access-токена | все |
| `GET` | `/users/` | Список всех пользователей | admin |

### Категории

| Метод | Путь | Описание | Роли |
|---|---|---|---|
| `GET` | `/categories/` | Список активных категорий | все |
| `POST` | `/categories/` | Создание категории | admin |
| `PUT` | `/categories/{id}` | Обновление категории | admin |
| `DELETE` | `/categories/{id}` | Мягкое удаление категории | admin |

### Товары

| Метод | Путь | Описание | Роли |
|---|---|---|---|
| `GET` | `/products/` | Список активных товаров | все |
| `GET` | `/products/{id}` | Детали товара | все |
| `GET` | `/products/category/{id}` | Товары по категории | все |
| `POST` | `/products/` | Создание товара | seller |
| `PUT` | `/products/{id}` | Обновление товара | seller |
| `DELETE` | `/products/{id}` | Мягкое удаление товара | seller |

### Отзывы

| Метод | Путь | Описание | Роли |
|---|---|---|---|
| `GET` | `/reviews/` | Список всех отзывов | все |
| `GET` | `/products/{id}/reviews` | Отзывы о товаре | все |
| `POST` | `/reviews/` | Создание отзыва | buyer |
| `DELETE` | `/reviews/{id}` | Мягкое удаление отзыва | автор / admin |

## Модели данных

- **User** — email, роль (`buyer`/`seller`/`admin`), активен ли
- **Category** — название, иерархия (parent_id), активна ли
- **Product** — название, описание, цена, изображение, остаток, рейтинг, привязка к категории и продавцу
- **Review** — пользователь, товар, оценка (1–5), комментарий, дата
